# analog-study: Sin-CNN2 をアナログ回路・FPAA で動かす検討

Sin-CNN2（正弦の干渉と回折だけで作る文字列分類器）の計算を、アナログ回路や FPAA（設定で回路を組み替えられるアナログ IC）に置き換えられるかを調べたもの。
詳しい結果と数値は [NOTES.md](NOTES.md)。

## 一言で
Sin-CNN2 の「位置」を「時間」と読み替えると、順伝播（推論）は **FSK 発振 → 位相変調 → 分散フィルタ を 16 段 → バンドパス + 2 乗検波** という、無線機の受信回路に近い形になる。
デジタルで一番重い FFT は、アナログではフィルタに通すだけになる。

## 最新（実験A03）
回折を弱めても（板の間隔 64 → 2）正解率はほぼ同じで、回折の代わりは **2 次全域通過フィルタ 1 段**で足りる。中構成 8 層で 94%。
FPAA の Okika OK2902A（CAB 56 個）に 8 層が載る見込み（約 33〜42 CAB、推定）。

## 長所
- 重み行列がなく、学習する値は位相変調の振幅と位相だけ（標準構成で約 2000 個）。**4 bit の精度で十分**。
- 各段の雑音は SNR 20 dB まで、検出器の雑音は 10 dB まで、ほぼ劣化しない。
- 各段の「明るさを 1 に戻す」処理は理想的には不要（明るさが保存されるため）。
- 検出は狭いバンドパスと 2 乗検波を検出器の数（4〜16 本）だけ用意すればよい。

## 短所
- **分散フィルタ（回折の代わり）の特性が 1% ずれると大きく劣化**する。実機の特性を測って学習に使う較正が必須。
- FPAA は小さすぎ・遅すぎで、標準構成（16 層）は載らない。数百 kHz 帯なら CPU より遅い。
- GPU より速くするには、数百 MHz 以上の帯域（SAW 部品などの RF 部品）か、系統の並列化が要る。

## 向いている使い方
- FPAA: 小さい構成（L=512、4〜8 層、学習する値 133〜517 個で 81〜95%）の原理実証、検出器部分だけの実装。
- RF 部品（SAW 分散遅延線・位相変調器）: 本番規模の高速・低消費電力な推論。
- 学習は当面「計算機で学習して値を書き込む」か「順伝播だけ実機」から始める。
